# Trocata

App for trading 2026 World Cup stickers. It brings together four collectors in the same area who have matching duplicates and missing stickers, so they can meet and trade.

This is not a Panini or FIFA product. The catalogue follows the album's public numbering. Images are cards generated by the app, or photographs under a free licence.

## How it works

Each person creates an account, sets where they are and how far they are willing to travel, and marks the stickers they have spare and the ones they still need.

When someone looks for a group, Trocata checks other people nearby who also want to trade and are not already in a group. It starts inside the chosen radius. If no group is possible, the search widens a little, up to 50 km.

It then builds groups of four: the person who searched, plus three others. A group only counts if the trades are real:

- a duplicate sticker can only be given to one person;
- each person receives at least one sticker they are missing.

Possible groups are ranked by how many stickers change hands, by how much more complete each album becomes, and by how close the people are. The person searching sees the best group and a few alternatives.

When they accept, the four people are reserved. Each one confirms, and the group arranges the meetup (there is a place to paste a WhatsApp link). While the group is open, those people do not join another one.

## Run locally

```bash
npm install
cp .env.example .env.local   # fill in the keys for your Supabase project
npm run dev                  # http://localhost:3000
```

Keys stay in `.env.local` only. That file is not committed. The `service_role` key is secret and is used on the server only.

The database (Postgres, PostGIS, and auth) is set up in Supabase. The steps are in [`docs/SETUP_SUPABASE.md`](docs/SETUP_SUPABASE.md).

Stack: Next.js and Supabase.

| Command | What it does |
|---|---|
| `npm run dev` | Local server |
| `npm test` | Matching algorithm tests |
| `npm run seed:cromos` | Sticker catalogue |
| `npm run seed:users` | Fake accounts to try matching. Requires `SEED_USER_PASSWORD` in `.env.local` |
